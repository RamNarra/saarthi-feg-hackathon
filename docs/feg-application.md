# FEG Innovation Hackathon 2026 — Challenge 1 Submission

### Challenge
**Challenge 1 — Session Quality and User Conversion**

### Project / Proposed Solution Title
**Saarthi — Real-Time Session Intelligence & Friction Resolution**

### Proposed Solution Approach Overview
Saarthi is a real-time session intelligence layer that understands what a user is trying to accomplish, detects where their session is getting stuck, and determines whether assistance would genuinely reduce friction. Rather than maximizing interactions or pushing recommendations, Saarthi chooses the smallest useful intervention — help, wait, or deliberately do nothing.

It combines session-sequence analysis, friction detection, real-time decisioning, and an intervention governor with explicit user-agency and responsible-play constraints. Saarthi can identify patterns such as repeated comparisons, navigation loops, information overload, and decision hesitation, then surface contextual assistance such as comparison, relevant information, narrowing, resume actions, or grounded explanations.

A High-Value Session metric and experimentation layer measure whether interventions improve meaningful session outcomes rather than simply increasing activity. The architecture is designed as a low-latency event-driven decision layer that can evolve into a production platform.

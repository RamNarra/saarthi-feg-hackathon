# Saarthi 60-Second Demo Presentation Script

1. **Thesis (0-15s)**: "Users don't always abandon because they aren't interested. Sometimes they're stuck. Saarthi is real-time session intelligence that understands what a user is doing, identifies friction, and decides whether to help, wait, or do nothing."
2. **Scenario A (15-25s)**: "Here the user browses normally. Saarthi observes fluent navigation and deliberately chooses DO NOTHING."
3. **Scenario B (25-45s)**: "In Scenario B, the user alternates repeatedly between Arsenal and Liverpool. Saarthi detects DECISION_HESITATION with 91% confidence, and offers a minimal side-by-side comparison. The user accepts and friction is resolved."
4. **Scenario C & D (45-60s)**: "If a user dismisses, our fatigue guard suppresses further interruptions. If a policy rule applies, the governor explicitly blocks candidate actions. All decisions execute in sub-millisecond time with zero pressure."

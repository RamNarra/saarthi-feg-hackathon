# Responsible AI & Player Protection Framework

Saarthi enforces non-negotiable player protection and ethical guidelines:

1. **Zero Dark Patterns**: Never uses urgency cues, countdowns, or deceptive promotional nudges.
2. **Smallest Useful Intervention**: Surfaces minimal contextual aids (side-by-side compare, narrow filter, resume).
3. **Adaptive Fatigue Guard**: User dismissal immediately suppresses further popups for the rest of that journey.
4. **Explicit Restraint ('Do Nothing')**: Silence is an intentional, successful product state when no friction is observed.
5. **Full Audit Trace**: Every single governor execution outputs input features, confidence ratings, policy status, and decision rationale.
